# Weather Tracker
A python application that fetches real-time data and stores it in a database. This was built for [CSIS-1230 - Programming for Everyone II]

## Features
- Fetches present-time weather data from Open-Meteo API
- Stores data in PostgreSQL database
- Returns requests data either individually or entirely through IDs
- Offers a downloadable copy of data currently in the system


# Installation
**Required Software**
- Python 3.13.7
- PostgreSQL Server 18.0

**Python Packages**
- requests
- flask
- "psycopg[binary]"

# Usage

1. Opening program:
```bash
python main.py
```

2. Opening file folder:
``` bash
cd weather_tracker
```

3. Run application in web browser:
